# Themes

Give DotCraft a look that suits the work: new app colors, a picture or animated scene behind the app, or a theme you describe to the Agent. A theme can apply to one chat, one project, or everywhere.

## Choose a theme

Run the **Theme** command from the Composer's command picker. A row of themes for the current appearance opens above the Composer. Select one and it applies everywhere right away.

To give one chat its own look, turn on **Only this chat** before selecting a theme. That chat keeps its theme while every other chat uses the one chosen everywhere. In this mode, **Default** returns the chat to the theme used everywhere, and **No theme** shows the ordinary app in that chat alone.

Each theme is made for light or dark appearance. Many come as a pair, and applying one applies both, so the look carries over when the appearance changes.

**Settings → Themes** shows the whole library. Selecting a theme there applies it everywhere. This is also where you add, import, and remove themes.

Themes is a bundled plugin. If the command and settings page are missing, enable **Themes** in **Settings → Plugins**.

## Use your own picture

In Themes settings, select **Add image** and choose a JPEG, PNG, or WebP up to 8 MB. The picture becomes a theme and applies everywhere. Below the themes, set how it fits the window.

## Create your own

Select **Create** in Themes settings. A new chat opens with a request ready in the Composer. Add what you want and send it, for example:

> Make a quiet night reef with slowly drifting light, a dark blue app surface, and readable warm text.

The Agent saves a theme and previews it with the theme picker open. Select the theme to keep it, or continue the chat to adjust it. Saving a theme alone does not change how DotCraft looks.

Select **Edit** on a theme to refine it. Editing an included theme creates your own copy. Your themes stay on this device even if you delete the chat where they were created.

## Keep text readable

Themes with a backdrop show it through the sidebar, chat, and Composer. In Themes settings, **Blur** softens the backdrop behind them and **Surface opacity** makes them more solid. Both start at their lowest setting and stay the same when you switch themes.

## Keep motion comfortable

Turn off scene animation to keep each scene's composed still picture. Scenes also become still when your system requests reduced motion or the window is hidden.

## Share a theme

Export a theme as JSON, then import it in Themes settings on another device. Import adds a copy to the local library and applies it. Use **Remove** to delete a theme you no longer need.
