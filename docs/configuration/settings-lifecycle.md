# Settings lifecycle

Desktop shows the action that applies each setting.

![When Desktop settings take effect](/settings-tiers-overview.svg)

## When changes take effect

| Setting | What to do |
|---|---|
| Skills and MCP servers | Save to apply immediately. |
| Channel plugin settings | Save, then reconnect the channel. |
| Local AppServer runtime and listener | Select **Apply & Restart**. |
| Remote AppServer connection | Select **Apply & Connect**. Desktop saves the connection after a successful test. |
| Default model and preferences | Save to apply to new chats. Existing chats keep their selections. |

## Fix a remote connection

On the connection error screen, select **Open Settings** to correct the URL or token, or switch to Local.

See [Configuration](./) for how personal and workspace settings combine.
