# 从其他 Agent 导入

把 Claude Code、ChatGPT 或 Cursor 中的工具、项目指令和对话带入 DotCraft。你可以继续使用熟悉的技能，翻看之前的对话，并在这里接着聊。

只有属于当前项目的对话会被导入。其他目录下的对话保持原样。

## 适用场景

- 你正把一个项目迁到 DotCraft，不想丢掉一路走来的对话。
- 你仍会用别的 agent 处理部分任务，但希望在一个地方回顾全部记录。

## 选择导入内容

1. 在项目里打开 **设置 › 导入**。
2. 点击应用旁的 **导入**，选择要带入的内容。
3. 查看目标位置后确认。已有配置不会被覆盖。

**工具与设置**会在当前主机的所有 DotCraft 项目中使用，**当前项目的配置**只影响打开的项目。远程连接时，来源文件和目标位置都在远程主机上。

DotCraft 支持导入技能、指令、Hooks、MCP 服务器和插件。指令会转为 `AGENTS.md`。导入指令和技能说明中的产品名称会替换为 DotCraft。插件内的内容随插件一起保留。

导入后，在 **需要处理** 中审核 Hooks 或完成工具连接。Hooks 在获得信任前不会执行。**导入历史**显示成功、失败和待审核的结果，并提供打开导入内容的入口。

导入的对话会出现在对话列表里，并带有标明来源应用的标记。打开就能阅读，发一条消息就能用 DotCraft 继续。

## 会导入哪些内容

你的消息和 agent 的回复会原样导入。工具活动，例如 agent 运行过的命令、改过的文件，会以简短的文字说明保留在回复里。推理过程和图片不会导入。

每次导入只取最近的对话：最近 30 天内有变化的，按最新排序，每个应用最多 50 条。已经导入过、之后又有新内容的对话，下次导入时会补上新增的消息。

一旦你在 DotCraft 里继续了某条导入的对话，它就归 DotCraft 所有。原应用里后来追加的消息不会再合并进来。

## 保持同步

开启同步后，DotCraft 会在项目运行期间检查你导入过的应用。之后的手动导入只会调整本次展示过的类别。在 **同步内容 › 自定义** 中选择类别，也可以明确选择同步所有类别及以后新增的类别。工具和配置只补充缺失项，不替换或删除已有内容。如果删除了导入项，而该类别仍在同步，后续同步可能再次导入它。

在 **设置 › 导入** 中关闭同步即可暂停，已选内容和已导入的数据都会保留。点击 **重新检查** 可立即刷新可导入内容。
