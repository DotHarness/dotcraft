# 社交渠道

把 DotCraft 接入 QQ、企业微信、飞书 / Lark、Telegram 或微信。渠道与 Desktop 共用工作区的对话记录和记忆。

![DotCraft 渠道适配器拓扑](/channel-adapter-topology.svg)

## 接入渠道

1. 在 DotCraft Desktop 打开工作区，进入**插件 → 渠道**。
2. 选择要接入的平台，点**安装**。
3. 按平台的接入步骤操作，然后点**设置**填写所需凭据。
4. 点**连接**。如果出现登录提示，先完成登录，再给 Bot 发一条测试消息。

接入其他平台时，安装对应的[渠道插件](../../extend/channel-modules)。

## 官方渠道插件

| 平台 | 接入方式 | Agent 能发送的内容 | 工作时的提示 | 设置 |
|---|---|---|---|---|
| **QQ** | NapCat 或 OneBot v11 反向 WebSocket | 文本、图片、文件、语音、视频 | 请求失败时发一条通知 | [QQ 设置](./qq) |
| **企业微信 / WeCom** | 群机器人回调 URL、Token、EncodingAESKey | 文本、图片、文件、语音 | 请求失败时发一条通知 | [企业微信设置](./wecom) |
| **飞书 / Lark** | 启用 Bot 和 WebSocket 事件订阅的自建应用 | 带格式的文本、图片、文件、音频、视频 | reaction、状态卡片 | [飞书设置](./feishu) |
| **Telegram** | BotFather token | 带格式的文本、图片、文件、音频、视频 | 正在输入提示，请求失败时发一条通知 | [Telegram 设置](./telegram) |
| **微信 / Weixin** | 腾讯 iLink 二维码登录 | 文本、图片、文件 | 请求失败时发一条通知 | [微信设置](./weixin) |

## Agent 在聊天里怎么说话

- Agent 工作时，可以再发一条消息，在同一个 DotCraft 对话里补充细节或调整方向。
- 回复格式和媒体类型见上表。发往其他聊天时，按提示审批。
- 在发起请求的聊天里处理审批和补充提问。在 Desktop 打开同一个工作区，即可查看记录或继续对话。

### Agent 工作时

飞书会给消息加上表情回应，工作超过 20 秒时显示状态卡片。Telegram 会显示正在输入。请求失败时，机器人会更新状态卡片或在聊天里发一条简短通知。

## 聊天中的命令

命令单独作为一条消息发送。命令会立即执行，Agent 正在工作时也一样。

| 命令 | 作用 |
|---|---|
| `/new` | 在这个聊天里开一段新对话。之前的对话仍可在 `/sessions` 中找到。 |
| `/stop` | 停止当前的工作。后台任务继续运行。 |
| `/stop all` | 停止当前的工作，丢弃排队的消息，并停止所有后台任务。 |
| `/tasks` | 列出后台任务。`/tasks stop <n>` 停止其中一个。 |
| `/status` | 显示对话在做什么：状态、模型、模式、上下文用量，以及排队或等待审批的内容。 |
| `/model [model]` | 列出可用模型，或把这个对话切换到某个模型。仅限管理员。 |
| `/mode [agent\|plan]` | 显示或切换模式。 |
| `/sessions` | 列出这个聊天最近的对话。 |
| `/resume <n>` | 回到 `/sessions` 里的第 `n` 个对话。 |
| `/compact` | 压缩对话上下文。 |
| `/automate list\|show\|pause\|resume\|run\|remove` | 管理从这个聊天创建的自动化。仅限管理员。 |
| `/help` | 列出你能使用的命令。 |
| `/init` | 创建一个写有 DotCraft 指令的 `AGENTS.md` 文件。仅限管理员。 |
| `/debug` | 开关调试模式。仅限管理员。 |

`/new` 和 `/resume` 会先停止当前工作，再切换对话。在 Agent 空闲时运行 `/compact` 和 `/init`。

命令给出选项时，例如 `/model` 列出的模型，在飞书或 Telegram 中点按钮，在其他平台发送编号列表里对应的命令。

用文字处理你发起的工作所需的审批时，回复 `/approve` 同意，`/deny` 拒绝，或用 `/approve session` 在本对话中允许同类操作。也可以分别回复 `同意` 或 `yes`、`拒绝` 或 `no`、`同意全部` 或 `approve all`。审批请求到期后自动取消。

在[渠道配置](../../configuration/channels)中用 `adminUsers` 授予管理员命令权限。微信机器人的所有者拥有管理员权限。

## 从聊天创建的自动化

让 Agent 按计划运行任务。结果和失败通知会发回创建任务的聊天。用 `/automate` 或 Desktop 的**自动化**页面管理任务。

## 把 Desktop 对话接到聊天里

在 Desktop 对话里输入 `/bind`，选一个已连接的渠道。DotCraft 会给出一条 `/bind 482913` 这样的命令，10 分钟内在目标聊天里发送它。之后那个聊天的消息会进入这个对话，Agent 也会把回复发到那里。

要在该聊天中重新使用 `/new`、`/sessions` 或 `/resume`，请先发送 `/unbind`，或在 Desktop 对话的 **⋯** 菜单中选**停止在 … 中继续**。

## 开放到群聊之前

- 文件和 Shell 操作保持需要审批。
- 平台支持时，把渠道限制到可信的用户、群或聊天。
- 把管理员权限授予负责选择模型和管理自动化的人。
- 公网回调地址使用 HTTPS。
