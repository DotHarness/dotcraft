# 主题

为 DotCraft 换一个适合当前工作的外观：新的应用配色、应用背后的图片或动态场景，或让 Agent 按你的描述创作。主题可以只用于一个对话、一个项目，或用于全局。

## 选择主题

在输入框的命令列表中运行**主题**命令。输入框上方会出现一排适用于当前外观的主题。选中一个，它会立即在全局生效。

想让某个对话使用单独的外观，先打开**仅此对话**，再选择主题。这个对话会保留自己的主题，其他对话继续使用全局主题。在这个模式下，**跟随默认**让对话回到全局主题，**无主题**只让这个对话显示普通界面。

每个主题为浅色或深色外观而作。很多主题成对提供，应用其中一个会同时应用另一个，切换外观时风格保持一致。

**设置 → 主题**显示完整的主题库，在这里选择的主题会在全局生效。添加、导入和移除主题也在这里。

主题是捆绑插件。如果没有看到命令和设置页，请先在**设置 → 插件**中启用**主题**。

## 使用自己的图片

在主题设置中点击**添加图片**，选择不超过 8 MB 的 JPEG、PNG 或 WebP。图片会成为一个主题并在全局生效。在主题列表下方可以设置它在窗口中的填充方式。

## 创作自己的主题

在主题设置中点击**创作**。会打开一个新对话，输入框里已经填好请求。补充你想要的效果后发送，例如：

> 做一个安静的夜间珊瑚礁背景，光线缓慢漂动，应用表面用深蓝色，文字用清晰的暖色。

Agent 会保存主题，并打开主题选择器预览它。选中这个主题即可保留，也可以继续对话调整效果。仅保存主题不会改变 DotCraft 的外观。

在主题上点击**修改**可以继续创作。修改内置主题会生成你自己的副本。即使删除创作时的对话，你的主题仍保留在本机。

## 保持文字清晰

带背景的主题会透过侧边栏、对话区和输入框显示背景。在主题设置中，**模糊**让它们背后的背景变柔和，**界面不透明度**让它们更接近实色。两者默认都是最低值，切换主题时保持不变。

## 调整动态效果

关闭场景动画后，每个场景会保留为构图完整的静态画面。当系统要求减少动态效果或窗口隐藏时，场景也会静止。

## 分享主题

将主题导出为 JSON，然后在另一台设备的主题设置中导入。导入会在本机主题库中新增一个副本并应用它。不再需要的主题可以点击**移除**删除。
