# DotCraft 卫星

卫星让你的 DotCraft 在另一台 Windows 电脑上工作。你在 Desktop 中继续对话，共享电脑的人决定 Agent 能做什么、看到它正在做什么，并能随时暂停。在 Desktop 中启用内置卫星插件，即可管理电脑、选择执行位置和查看远程屏幕。

![邀请方的电脑运行 Desktop 和 Hub，共享电脑上的卫星主动连接邀请方](/satellite-overview.svg)

## 发起邀请的人：创建邀请

打开**设置 → 卫星**，点击**邀请**。复制链接发给对方即可。

首次邀请时，如果 Windows 询问是否允许 DotCraft 通过防火墙，请在你信任的专用网络上允许。共享电脑需要能够访问邀请链接中的地址。

## 共享电脑的人：安装并打开卫星

在要共享的电脑上打开邀请链接，确认是谁在申请，点击**下载 DotCraft 卫星**。安装完成后会打开**共享这台电脑**窗口。如果已经安装卫星，使用邀请页面的打开卫星入口。

## 共享电脑的人：选择授权方式

### 完全授权

点击**允许连接**。之后 Agent 可以用你的 Windows 权限读写文件、运行命令，无需逐次确认。只有在你信任对方操作这台电脑时，才选择这个方式。

![英文授权窗口左侧选中完全授权，右侧是仅授权文件夹](https://github.com/DotHarness/resources/raw/master/dotcraft/satellite/authorize-full.png)

### 仅授权文件夹

点击**仅授权文件夹**并选择要共享的文件夹，或取消选择以使用建议的任务文件夹。Agent 可以读写这个文件夹，其他操作包括运行本机命令都要等你确认。这不是严格的沙箱。

![英文授权窗口选中仅授权文件夹，显示所共享的文件夹和更换入口](https://github.com/DotHarness/resources/raw/master/dotcraft/satellite/authorize-workspace.png)

点击**拒绝**即可拒绝这次邀请。

## 发起邀请的人：选择执行位置

对方允许连接后，打开对话输入框下方的**执行位置**，选择远程电脑及其工作区，然后提交任务。文件、Shell 和语言工具会在那台电脑上执行。选择**本机**即可切回本地。

Agent 仍然可以访问你本机的文件，并按需在两台电脑之间复制文件或文件夹。例如：“把我本地的检查 CLI 上传到远端工作区，再在那里运行。”

## 发起邀请的人：查看远程屏幕

对话在远程电脑上执行时，点击对话标题栏里的**查看 … 的屏幕**，就能打开那台电脑桌面的实时画面。画面可以随意拖动和缩放，把指针移上去会出现**放大**和**停止查看**。画面只能看，不能操作。

## 共享电脑的人：看到谁在用这台电脑

这台电脑配对后，屏幕顶部的悬浮条会显示谁已连接、Agent 正在做什么。有工具在运行时，屏幕边缘会亮起。点击悬浮条可以看到每台已连接的电脑，断开其中一台，或打开它的任务文件夹。点击悬浮条上的暂停按钮会一次停止所有电脑，点击**恢复共享**即可继续。

对方正在查看你的屏幕时，悬浮条上会显示一个眼睛图标。

## 共享电脑的人：处理额外访问

仅授权文件夹模式下，额外访问请求会出现在悬浮条上。核对是谁在申请以及具体路径或命令，再点击**允许一次**或**拒绝**。运行命令可能影响任务文件夹之外的文件。两分钟内无人回应的请求会被拒绝。

![英文悬浮条询问是否允许 Ann 运行命令，带拒绝和允许一次](https://github.com/DotHarness/resources/raw/master/dotcraft/satellite/approve-command.png)

## 共享电脑的人：查看、暂停或收回权限

右键点击卫星托盘图标并选择一台电脑，可以更改它的授权方式、打开任务文件夹、断开连接或撤销授权。同一菜单中的**暂停共享**会停止所有电脑，直到你恢复。

如果这台电脑也安装了 Desktop，**设置 → 卫星 → 共享这台电脑**会显示谁有访问权限以及授权方式。

![英文共享这台电脑页面显示两个共享对象及各自的授权方式和任务文件夹](https://github.com/DotHarness/resources/raw/master/dotcraft/satellite/manage-access.png)

发起邀请的人也可以在**设置 → 卫星**中移除电脑。重新共享需要新的邀请。
