# 交互式回答

当计算器、方案对比或小测验比一段文字更能回答问题时，DotCraft 会直接在回复里放一个。边看边调，用里面的按钮继续追问或复制结果。Desktop 用和应用其他界面相同的控件来呈现它。

## 让日常问题的回答更好用

纯文字回答只是一张快照。多来一位客人、换一家酒店、某个月流量多用了些，就得重新问一遍。交互式回答把这些条件留在回复里，你自己改，结果跟着变。在文字回答和交互式回答之间切换，对比一下。

<LiveExample feature="generative-ui" compare :examples="['dinner', 'plans', 'trip']" :height="800" />

回复的文字部分照样写明答案。复制这条消息、在其他客户端里查看，或者只看到通知，结论都不会丢。

## 直接要一个工具

直接说想要什么工具，DotCraft 当场做出来，比如贷款计算器、单位换算，或者考前的小测验。

<LiveExample feature="generative-ui" :examples="['mortgage', 'unit-converter', 'quiz']" :height="640" />

## 想要时就能要到

交互有没有帮助由 DotCraft 自己判断，大多数时候直接提问就行。想确保拿到一个，就说清你想调整什么、做什么，比如“给我一个能改利率和年限的计算器”或者“出三道题考考我”。

交互式回答只在 Desktop 中显示。CLI、聊天机器人等其他入口显示的是同一条回复的文字部分。

## 怎么用

滑块、输入框和选项一改，结果立即更新，重新打开对话后你的调整依然保留。按钮可以发送追问、把内容填进输入框等你补充、复制结果，或在你确认后打开链接。DotCraft 写完回复后，这些控件才会启用。

需要自由绘制的图形、模拟演示或设计稿时，DotCraft 会改用[交互式可视化](./visualizations)。
