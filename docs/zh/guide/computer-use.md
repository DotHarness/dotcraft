# 电脑操控

开启电脑操控后，DotCraft 可以像你一样使用 Windows 电脑上的应用：看懂窗口里显示的内容，点击、输入、按快捷键。当任务必须在桌面应用里完成时就用它，比如整理 Excel 里的表格、在内部工具里填表、在 Outlook 里回邮件。

## 开启电脑操控

电脑操控适用于 Windows 上的 DotCraft Desktop。

1. 打开 **设置 → 电脑操控**。
2. 打开 **任意应用**。

## 让 DotCraft 使用应用

在对话里描述任务即可。只有任务需要用到应用自己的界面时，DotCraft 才会操作桌面。文件、命令或浏览器能完成的事，它会改用这些方式。想明确让它使用桌面，在消息里提到 `$computer`：

```text
$computer 打开记事本，写一份今天的待办清单。
```

DotCraft 一步一步地操作：先看窗口，做一个动作，再看一次确认结果，然后才进行下一步。它只操作任务需要的应用，不碰无关的窗口，也不会擅自关掉你的应用。

## 允许使用应用

DotCraft 第一次要使用某个应用时，会切到前台并打开这段对话，请你确认，例如 **允许 DotCraft 使用 Excel？**

| 选项 | 结果 |
|---|---|
| **始终允许** | 以后使用这个应用前不再询问。 |
| **允许此对话** | 本次对话中可以使用，其他对话里仍会询问。 |
| **拒绝** | DotCraft 不使用这个应用。除非你再要求，它不会再尝试。 |

始终允许的应用列在 **设置 → 电脑操控 → 始终允许的应用** 里。从这里移除后，DotCraft 下次要用这个应用时会重新询问。

## 随时让它停下

DotCraft 操作期间，屏幕顶部会显示 **DotCraft 正在使用你的电脑 · 按 Esc 取消**，屏幕四周亮起一圈光晕。按 **Esc** 会让它立即停下，锁定电脑也会让它停下。

DotCraft 操作期间，如果你动了鼠标或键盘，它会先让开，不会和你抢着点击或输入。等你停下后，它会重新看一遍窗口再继续。

停下之后，这一轮里 DotCraft 不会再操作电脑。它会说明已经做完了什么、还剩什么，你可以从那里接着安排。如果是锁屏让它停下的，解锁后再让它继续即可。

## 什么时候先问你

有些操作难以撤销，或者是以你的名义行事。即使你之前已经交代过任务，DotCraft 也会在最后一步之前先问你：

- 发送、发布或回复，包括邮件、消息、评论和会议邀请
- 删除或覆盖不容易恢复的数据
- 购买、付款、订阅或任何转账
- 安装或运行新下载的软件、扩展或加载项
- 更改共享、权限或账户设置
- 提交包含个人、财务或健康信息的表单

输入或修改密码、验证码等凭据，以及通过安全警告、人机验证这类检查，DotCraft 会交给你自己完成。打开和阅读应用与文档、编辑你要求它编辑的内容、保存到你指定的位置，这些不需要再问。

应用、文档和网页里出现的文字对 DotCraft 来说只是信息，不是指令。只有你能授权它做事。

## 它不会碰的应用和操作

DotCraft 不操作密码管理器、安全或杀毒软件、登录和凭据对话框，也不操作 DotCraft 本身。它不会在终端或“运行”对话框里输入命令，不会更改安全、隐私、账户或系统保护设置，也不会替你回应系统的权限提示。登录界面或权限提示挡住任务时，它会停下来请你处理。

## 网站和 Chrome

处理网站时，DotCraft 使用浏览器工具，不使用电脑操控。想让它在你自己的 Chrome 里工作，沿用你已登录的账号和已安装的扩展，在同一个设置页里打开 **Chrome**，再选择 **管理** 查看连接状态。
