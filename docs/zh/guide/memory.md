# 记忆与梦境

DotCraft 会在同一个工作区的会话之间记住以后还用得上的东西：你是谁、你希望它怎么做事、仓库里没写下的项目背景，以及外部资料在哪里。记忆就是工作区里的普通 Markdown 文件，随时可以查看和修改。开启梦境后，DotCraft 还会在后台定期整理这些记忆。

![DotCraft 记忆使用流程](/memory-lifecycle-topology.svg)

## DotCraft 会记住什么

直接告诉 DotCraft 要记住、更正或忘记什么，例如：“记住我喜欢简短的回答。”它会在这次回复里就把记忆改好。

没有明确要求时，DotCraft 也会主动保存以后的会话用得上的知识。每条记忆属于以下四类之一：

| 类型 | 保存什么 |
|---|---|
| `user` | 你的角色、专长和偏好 |
| `feedback` | 你希望它怎么工作，包括你纠正过的做法和你认可过的做法 |
| `project` | 仓库里没有记录的目标、决定和约束，日期一律写成具体日期 |
| `reference` | 工作区之外的资料在哪里，比如某个看板或问题跟踪系统 |

仓库或 `AGENTS.md` 已经写明的内容，比如代码结构、修过的问题和历史记录，以及只和当前任务有关的内容，它不会主动保存。拿不准一条信息以后还用不用得上时，它也不保存。已有记忆覆盖到的内容，它会更新原来那条，不会再添一条重复的。被证明有错的记忆会被删掉。

## 记忆存在哪里

记忆存放在工作区的 `.craft/memory/` 目录里，每条记忆一个 Markdown 文件，开头写明名称、一行描述和类型：

```markdown
---
name: prefers-short-answers
description: User wants brief answers without a closing recap
metadata:
  type: feedback
---

Keep answers short and skip the closing summary.

**Why:** The user reads replies between meetings.
**How to apply:** Lead with the answer and offer detail only when asked.
```

同一目录下的 `MEMORY.md` 是索引，每条记忆占一行，例如 `- [Prefers short answers](prefers-short-answers.md) — brief replies, no recap`。你可以随时手动新建、修改或删除记忆文件，同时改好它在 `MEMORY.md` 里的那一行。

## 会话如何用上记忆

每次会话一开始，DotCraft 就能看到 `MEMORY.md` 索引，遇到和任务相关的记忆再打开对应文件。记忆只代表保存那一刻的情况，你当前的指示和它在工作区里实际看到的内容优先。记忆提到某个文件、函数或设置时，DotCraft 会先确认它还在，再据此行动。读到较早的记忆时，它也会被提醒这条记忆可能已经过时。告诉它忽略记忆，它就不会使用、引用或提起记忆。

记忆一有改动，已经打开的会话也能看到，不管是你手动改的、别的会话保存的，还是梦境整理的。

在 Desktop 中，记忆的读写会直接显示在对话里。“已回忆 N 条记忆”列出这次读到的记忆文件，“记忆已更新”列出这次保存的文件，点 **管理** 可以打开记忆设置。

## 保存遗漏的记忆

DotCraft 通常在回复时保存记忆。想补上遗漏的内容，打开 **设置 → 个性化 → 保存遗漏的记忆**：每隔几次回复，DotCraft 会在后台检查对话中有没有值得记住但还没保存的内容。这些后台保存不会显示在对话里。这个开关只影响之后新建的会话。

## 梦境

![梦境审阅流程](https://github.com/DotHarness/resources/raw/master/dotcraft/docs/dreams.webp)

用得久了，记忆难免出现重复和过时的内容。梦境会在后台整理记忆：合并重复的记忆，修正和工作区现状不符的事实，让 `MEMORY.md` 保持简短。它还会核对记忆和 `AGENTS.md`，两者冲突时以 `AGENTS.md` 为准。如果某条记忆明显比 `AGENTS.md` 新，梦境会保留它，并在这次运行的总结里标出来等你确认。梦境不会修改 `AGENTS.md`。

在 Desktop 的 **设置 → 个性化 → 梦境** 中开启。之后只要 DotCraft 在运行，梦境就会自动运行，默认最多每天一次，而且要等上次整理以来已有几次会话用过记忆。在 **管理** 里可以调整频率，或点 **立即运行** 马上整理一次。

每次运行都会提出一份记忆改动，应用之前记忆保持原样。在 **管理** 的运行记录里点 **审阅**，会在 Dashboard 中打开这次运行。逐个文件对比改动前后的内容，再决定应用还是丢弃。应用之后反悔了，只要记忆之后没再变化，就可以在 Dashboard 里把记忆恢复成运行前的样子。如果运行期间记忆有了变化，这次结果就无法应用，重新运行一次梦境即可。

想让每次运行的结果直接生效，在 **管理** 里打开 **自动更新梦境**。已经在等待审阅的运行仍然等你审阅。

## 给 Agent 单独的记忆

[Agent 预设](./agent-profiles)默认和你在这个工作区的其他会话共用记忆。想让某个 Agent 只积累自己的记忆，编辑它时把 **记忆** 设为 **仅限此智能体**（预设文件里写作 `memory: own`）。它的记忆和其他会话互不相通，梦境也会单独整理它。

这份记忆跟着 Agent 的名称走，改名后会从空白记忆开始。删除或导出 Agent 都不会动它的记忆。

## 关闭或删除记忆

不想使用记忆时，在 Desktop 中关闭 **设置 → 个性化 → 启用记忆**。之后新建的会话既不使用也不保存记忆，已经打开的会话保持原来的设置。保存遗漏的记忆和梦境也会暂停，重新开启记忆后按原来的设置恢复。

只想忘掉一件事，直接告诉 DotCraft，或者自己删掉那个文件和它在 `MEMORY.md` 里的那一行。要清空整个工作区的记忆，打开 **设置 → 个性化 → 删除记忆**。这会删除工作区里的所有记忆，包括 Agent 和自动化单独保存的记忆，以及全部梦境运行记录。会话记录、设置、技能和 Agent 预设都会保留。
