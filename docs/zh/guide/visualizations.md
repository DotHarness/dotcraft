# 交互式可视化

让 DotCraft 把一组对比、一个原理或一份结果做成可以探索的东西，它会在回复里画出交互式可视化，比如可以悬停查看的图表、可以播放的模拟演示，或者几版可以来回翻看的设计稿。

## 怎么要一个

描述你想看到什么就行，比如“把今年和去年的用电量画成图”或者“演示一下月亮为什么有阴晴圆缺”，也可以直接调用 `$visualize`。当一张图比文字更能讲清楚时，DotCraft 也会主动画一个。

## 探索和修改

视图就在对话里运行，不用离开会话就能操作。提出修改后，DotCraft 会更新同一个可视化，之前回复里的视图也会切换到最新版本。你在可视化中做的选择会被保留，回到对话时依然在，DotCraft 的下一次回复也能参考这些选择。

## 对比设计方向

要设计稿时，DotCraft 可以把几版设计放进同一个视图。用预览下方的箭头切换方案，打开**设计调整**微调颜色、尺寸和布局。**添加到消息**会把你的改动放进输入框，DotCraft 就能把它们带进正式设计。

## 视图操作

把鼠标移到可视化上，可以把当前状态复制为图片，或者全屏打开。全屏时用方向键翻看对话里的每一个可视化。视图也可以发起追问，发送前会先请你确认问题内容。

计算器、小测验这类用 Desktop 自带控件做成的小工具，见[交互式回答](./interactive-answers)。
