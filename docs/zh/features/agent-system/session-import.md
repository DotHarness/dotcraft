# 从其他 Agent 导入

如果同一个项目你也在用 Claude Code、ChatGPT 或 Cursor，DotCraft 可以把那些会话导入到工作区里。你可以在 DotCraft 的会话列表里翻看它们，接着任意一条继续聊，项目打开期间新产生的会话也会自动进来。

只有属于当前项目的会话会被导入。其他目录下的会话保持原样。

## 适用场景

- 你正把一个项目迁到 DotCraft，不想丢掉一路走来的对话。
- 你仍会用别的 agent 处理部分任务，但希望在一个地方回顾全部记录。

## 导入会话

1. 在项目里打开 **设置 › 导入**。
2. 本机检测到的每个应用都会显示有多少条会话可导入。点击对应的 **导入**。
3. 保持勾选 **保持同步**，新的和更新过的会话就会自动进来，然后确认。

导入的会话会出现在会话列表里，并带有标明来源应用的标记。打开就能阅读，发一条消息就能用 DotCraft 继续。

## 会导入哪些内容

你的消息和 agent 的回复会原样导入。工具活动，例如 agent 运行过的命令、改过的文件，会以简短的文字说明保留在回复里。推理过程和图片不会导入。

每次导入只取最近的会话：最近 30 天内有变化的，按最新排序，每个应用最多 50 条。已经导入过、之后又有新内容的会话，下次导入时会补上新增的消息。

一旦你在 DotCraft 里继续了某条导入的会话，它就归 DotCraft 所有。原应用里后来追加的消息不会再合并进来。

## 保持同步

开启同步后，DotCraft 会在项目打开期间检查已连接的应用，把新内容导入进来。在 **设置 › 导入** 里可以关闭以暂停。你选择的应用会保留，重新开启无需再设置。**重新检查**会立刻检查一次。
