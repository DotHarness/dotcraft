# DotCraft 卫星

卫星让你的 Agent 在另一台 Windows 电脑上使用文件和运行工具，例如请同事共享一台已有代码仓库和构建环境的工作站。发起邀请的人在 Desktop 中继续对话，共享电脑的人在卫星中决定授权方式，并处理额外访问请求。

![邀请方的电脑运行 Desktop 和 Hub，共享方的电脑运行卫星并共享一个文件夹，由它向外拨号连上对方](/satellite-overview.svg)

## 发起邀请的人：创建邀请

打开**设置 → 连接 → 卫星**，点击**邀请**。填写用途，让对方知道你需要这台电脑做什么，然后生成并复制邀请链接，发给对方。

首次邀请时，如果 Windows 询问是否允许 DotCraft 通过防火墙，请在你信任的专用网络上允许。共享电脑需要能够访问邀请链接中的地址。

## 共享电脑的人：安装并打开卫星

在要共享的电脑上打开邀请链接，确认邀请人和用途，点击**下载 DotCraft 卫星**并完成安装。安装完成后会打开**共享这台电脑**窗口。卫星为当前 Windows 用户安装，不申请管理员权限。

如果已经安装卫星，使用邀请页面的打开卫星入口。

## 共享电脑的人：选择授权方式

### 工作区优先（推荐）

保留默认的**工作区优先**，直接点击**允许连接**即可使用建议的任务文件夹。要使用已有项目，点击该选项下面的**更换文件夹**，再允许连接。

Agent 可以直接读写任务文件夹，访问其他文件或运行本机命令时需要你确认。

![英文授权窗口选中工作区优先，任务文件夹和更换文件夹按钮位于该选项下方](https://github.com/DotHarness/resources/raw/master/dotcraft/satellite/authorize-workspace.png)

### 完全托管

只有在你信任对方操作这台电脑时，才选择**完全托管**。阅读警示，勾选确认，再点击**允许连接**。这个模式不显示任务文件夹选择。

完全托管允许使用你的 Windows 权限访问文件和运行命令，无需逐次确认，仍受操作系统权限和主机禁止策略约束。

![英文授权窗口选中完全托管，显示权限警示和确认勾选，不显示任务文件夹](https://github.com/DotHarness/resources/raw/master/dotcraft/satellite/authorize-full.png)

工作区优先通过额外访问确认来限制操作，不是严格的文件系统沙箱。任何模式下，点击**拒绝**都不会建立配对或创建建议的任务文件夹。

## 发起邀请的人：选择执行位置

对方允许连接后，在**设置 → 连接 → 卫星**中找到这台电脑。打开对话输入框下方的**执行位置**，选择远程电脑及其工作区，然后提交任务。

文件、Shell 和语言工具会在选中的电脑上执行。电脑离线或工作区被占用时，先等待它可用，再继续任务。远程执行失败不会自动改成本机执行。需要回到自己的电脑时，选择**本机**。

## 共享电脑的人：处理额外访问

工作区优先模式下，卫星会为额外访问打开审批窗口。核对邀请人、操作以及路径或完整命令，再点击**允许一次**或**拒绝**。运行命令可能影响任务文件夹之外的文件。

![英文审批窗口显示 Ann 请求运行 dotnet build Demo.sln，并提供拒绝和允许一次按钮](https://github.com/DotHarness/resources/raw/master/dotcraft/satellite/approve-command.png)

拒绝后，Agent 会收到结果。发起邀请的人不能代替你批准这次电脑访问。

## 共享电脑的人：查看、暂停或收回权限

如果这台电脑也安装了 Desktop，打开**设置 → 连接 → 共享这台电脑**，查看共享对象、授权方式和任务文件夹。权限变更在卫星中完成。

![英文共享这台电脑页面显示两个共享对象及各自的授权方式和任务文件夹](https://github.com/DotHarness/resources/raw/master/dotcraft/satellite/manage-access.png)

右键点击卫星托盘图标，选择**管理访问权限**（Manage access），再选择共享对象，即可更改授权方式。选择**暂停共享**可以停止共享，之后可恢复。选择**撤销**并选中共享对象，可以收回该对象的访问权限。

发起邀请的人也可以在**设置 → 连接 → 卫星**中移除电脑。重新共享需要新的邀请。
