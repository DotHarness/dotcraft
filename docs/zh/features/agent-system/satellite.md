# DotCraft 卫星

卫星是一个装在项目文件夹所在电脑上的托盘小程序。用邀请链接安装一次，批准你愿意共享的文件夹，同事的 DotCraft Agent 就能从他自己的机器上在那个文件夹里构建、测试和修改代码。谁连着、正在跑什么，你随时都能看到，也随时可以叫停。

卫星面向真正干活的那台电脑的主人。发出邀请的同事在自己那一侧使用 [Remote Tool Host](./remote-tool-host)。

## 从邀请链接安装

同事会发来一条形如 `http://ann-pc:47600/i/inv_x1y2z3` 的链接。在要共享的电脑上用浏览器打开它。页面会写明邀请人是谁、想做什么，并提供**下载 DotCraft 卫星**。

运行安装程序。它只为你这个用户安装，不需要管理员密码。

> [!NOTE]
> 在 DotCraft 为安装包签名之前，Windows SmartScreen 会弹出蓝色的「Windows 已保护你的电脑」。请选择**更多信息**，然后点**仍要运行**。

邀请页会不断尝试把链接交给卫星，所以安装完成后同意窗口会自己弹出来。如果你已经关掉了页面，重新打开链接即可。

## 批准共享内容

同意窗口是建立连接的唯一入口。它会显示谁在请求、邀请来自哪台电脑，以及对方为什么需要访问。

允许之前先确认文件夹。卫星会填入同事建议的文件夹，你可以用**更改…**换一个。请选择项目文件夹本身，不要选整块磁盘，也不要选你的用户目录。

允许之后，对方可以读取和修改这个文件夹里的文件，并在你的电脑上运行命令。这些权限仅在你保持登录时有效。

点**拒绝**不会留下任何痕迹。在你点**允许**之前，什么都不会被保存。

## 看懂托盘图标

卫星常驻在通知区域，图标上的彩色圆点表示当前状态：

| 圆点 | 含义 |
|---|---|
| 灰色 | 未连接。现在没有人能访问这台电脑。 |
| 蓝色 | 就绪。已连接，等待任务。 |
| 绿色 | 使用中。有人正在你的文件夹里运行任务。 |
| 琥珀色 | 已暂停。你暂停了共享，连接仍然保持。 |

右键点击图标打开菜单。菜单会写明谁在连接、从什么时候开始、当前正在运行的命令，并提供：

- **断开连接** —— 结束当前连接，对方之后仍可重新连接。
- **暂停共享** —— 在你恢复之前不接新任务。需要独占这台电脑时用它。
- **撤销** —— 彻底移除某个人。除非重新邀请，否则他不会再获得访问权限。
- **打开文件夹** —— 在文件资源管理器里打开共享的文件夹。
- **粘贴邀请链接…** —— 链接没有自动打开时，用它接受你复制好的邀请。
- **退出** —— 停止共享，直到下次登录。

如果这台电脑上也装了 DotCraft Desktop，**设置 → 连接 → 共享这台电脑**会列出同样的配对供你查看，改动仍然在托盘程序里进行。

## 开机自动启动

卫星会随 Windows 自动启动并静默驻留在托盘里，不弹任何窗口，所以同事随时能找到这台电脑，你什么都不用做。如果你更想自己手动启动，在**设置 → 应用 → 启动**里关掉 `DotCraft Satellite`。

## 卸载

在**设置 → 应用 → 已安装的应用**里卸载卫星。卸载时它会询问是否一并撤销所有人的访问权限。除非你马上要重装，否则请选择撤销。无论怎么选，卸载后共享都会停止。
