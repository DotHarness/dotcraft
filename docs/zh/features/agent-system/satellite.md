# DotCraft 卫星

卫星提供远程工具调用，让你的 Agent 在另一台 Windows 电脑上工作。你在 Desktop 中继续对话，共享电脑的人决定访问权限、查看工具执行活动，并能随时暂停共享。

![邀请方的电脑运行 Desktop 和 Hub，共享电脑上的卫星主动连接邀请方](/satellite-overview.svg)

## 发起邀请的人：创建邀请

打开**设置 → 连接 → 卫星**，点击**邀请**。对话框打开时链接已经生成，复制后发给对方即可。

首次邀请时，如果 Windows 询问是否允许 DotCraft 通过防火墙，请在你信任的专用网络上允许。共享电脑需要能够访问邀请链接中的地址。

## 共享电脑的人：安装并打开卫星

在要共享的电脑上打开邀请链接，确认是谁在申请，点击**下载 DotCraft 卫星**并完成安装。安装完成后会打开**共享这台电脑**窗口。卫星为当前 Windows 用户安装，不申请管理员权限。

如果已经安装卫星，使用邀请页面的打开卫星入口。

## 共享电脑的人：选择授权方式

卫星把两种授权方式并排展示，各自说明允许什么。窗口打开时默认选中**完全授权**。

### 完全授权

点击**允许连接**。之后访问文件和运行命令都使用你的 Windows 权限，无需逐次确认。操作系统权限和主机禁止策略仍然生效，因此只有在你信任对方操作这台电脑时，才选择这个方式。

![英文授权窗口左侧选中完全授权，右侧是仅授权文件夹](https://github.com/DotHarness/resources/raw/master/dotcraft/satellite/authorize-full.png)

### 仅授权文件夹

点击**仅授权文件夹**，卫星会让你选择要共享的文件夹。取消选择则使用建议的任务文件夹，它只在你允许连接后才创建。卡片上的文件夹按钮可以换成另一个文件夹。

Agent 可以读写这个文件夹，访问其他文件或运行本机命令时需要你确认，这不是严格的文件系统沙箱。

![英文授权窗口选中仅授权文件夹，显示所共享的文件夹和更换入口](https://github.com/DotHarness/resources/raw/master/dotcraft/satellite/authorize-workspace.png)

点击**拒绝**不会建立配对，也不会创建建议的任务文件夹。

## 发起邀请的人：选择执行位置

对方允许连接后，在**设置 → 连接 → 卫星**中找到这台电脑。打开对话输入框下方的**执行位置**，选择远程电脑及其工作区，然后提交任务。

文件、Shell、语言工具和支持远程调用的 .NET 插件工具会在选中的电脑上执行。远程调用失败不会自动改成本机执行。选择**本机**即可切回本地。

Agent 也可以在不改变这个选择的情况下访问你本机的文件，并按需在两台电脑之间复制文件或文件夹。例如：“把我本地的检查 CLI 上传到远端工作区，再在那里运行。”覆盖已有文件需要显式指定。

对于支持远程调用的 .NET 工具，DotCraft 会自动在共享电脑上准备插件包、依赖和配置。Skill 指令仍在本机读取，配套文件按需传输。CLI 须支持共享电脑的操作系统。工具参数见[本地访问与文件传输](../../developing/architecture/remote-tool-host#本地访问与文件传输)。

## 发起邀请的人：查看远程屏幕

对话在远程电脑上执行时，点击对话标题栏里的**查看 … 的屏幕**，就能打开那台电脑桌面的实时画面。画面可以拖到任何顺手的位置，也可以从角上拉大缩小，把指针移上去会出现**放大**和**停止查看**。画面只能看，不能操作，也不会被录制。对方暂停共享或电脑掉线时，恢复共享后画面会自动回来。

## 共享电脑的人：看到谁在用这台电脑

只要这台电脑已配对，屏幕顶部就会有一个悬浮条，浮在其他窗口之上。有人正在使用你的电脑时，它写明谁已连接，有工具在运行时还会写明操作和它正在运行的命令。把指针移到悬浮条上，可以看到每一台已连接的电脑及其授权方式，断开其中一台，或打开它的任务文件夹。列表下方的**暂停共享**会一次停止所有电脑，点击悬浮条上的**恢复共享**即可继续。它挡住你手上的事情时，可以拖到别处，下次仍会回到你放的位置。

对方正在查看你的屏幕时，悬浮条上会显示一个眼睛图标，开始和停止查看时 Windows 都会通知你。**暂停共享**会立即结束查看。

## 共享电脑的人：处理额外访问

仅授权文件夹模式下，额外访问就在这个悬浮条上请求。核对邀请人、操作以及路径或完整命令，再点击**允许一次**或**拒绝**。运行命令可能影响任务文件夹之外的文件。请求一次只处理一个，两分钟内无人回应即视为拒绝。

![英文灵动岛询问是否允许 Ann 运行命令，带拒绝和允许一次](https://github.com/DotHarness/resources/raw/master/dotcraft/satellite/approve-command.png)

拒绝后，Agent 会收到结果。发起邀请的人不能代替你批准这次电脑访问。

## 共享电脑的人：查看、暂停或收回权限

如果这台电脑也安装了 Desktop，打开**设置 → 连接 → 共享这台电脑**，查看共享对象、授权方式和任务文件夹。权限变更在卫星中完成。

![英文共享这台电脑页面显示两个共享对象及各自的授权方式和任务文件夹](https://github.com/DotHarness/resources/raw/master/dotcraft/satellite/manage-access.png)

右键点击卫星托盘图标，选择一台电脑即可展开它的操作：**管理访问权限**（Manage access）更改授权方式，**打开文件夹**（Open folder）打开它的任务文件夹，**断开连接**（Disconnect）结束当前会话，**撤销授权**（Revoke access）收回访问权限。**暂停共享**会一次停止所有电脑，之后可恢复。

发起邀请的人也可以在**设置 → 连接 → 卫星**中移除电脑。重新共享需要新的邀请。
