# 手机 App

离开电脑时，也能在手机上跟进 DotCraft。Agent 照常在你的电脑上运行，手机 App 显示哪些聊天正在运行，把审批和提问摆到你面前，还能在电脑上的项目里开新聊天。

## 安装 App

在手机上从 [GitHub Releases](https://github.com/DotHarness/dotcraft/releases) 下载 `DotCraft-v<版本号>-android.apk`，打开即可安装。第一次安装时，Android 会请你允许浏览器或文件管理器安装应用。

目前只提供 Android 版本。

## 配对手机

1. 在电脑上打开 DotCraft Desktop，进入**设置 → 连接 → 手机**。
2. 打开**允许手机控制这台电脑**。
3. 点击**添加手机**，屏幕上会出现一个二维码。它只能使用一次，10 分钟后过期。
4. 在手机上打开 DotCraft，扫描二维码，再点击**允许**。

之后手机会出现在**已配对的手机**列表里。已配对的手机可以在这台电脑上执行你在 DotCraft 中能做的任何操作，所以只配对你自己的手机。不再使用时，在同一个列表里移除它。

手机需要和电脑处于同一网络，或同一个私有网络（例如 Tailscale）。在其他网络下使用，见[随处访问](#随处访问)。

## 跟进和回复聊天

App 首页最上方是**需要你处理**：所有运行中的项目里，等你审批或回答的聊天都排在这里。下面是项目和最近的聊天。

- **跟进**正在运行的聊天，实时看到它的进展。
- **审批**命令或文件改动，可选**允许一次**、**本会话允许**或**拒绝**。
- **回答** Agent 的提问，选一个选项或直接输入。
- 聊天运行时**追加消息**，或者**停止**它。
- 在电脑上的任意项目里**开新聊天**。项目没有运行时，发送后会自动启动。

手机和电脑显示的是同一批聊天，在一边开始的聊天可以在另一边接着聊。在一边答复了审批，另一边的提示也会消失。模型、设置和插件仍在电脑上管理，手机不会改动它们。

## 在后台继续

离开 App 时，如果还有聊天在运行或在等你，DotCraft 会保持实时会话，并显示一条常驻通知，例如“2 个运行中 · 1 个需要你处理”。新的审批会以通知弹出，带**允许一次**和**拒绝**按钮，不用打开 App 就能回复。新的提问和已结束的聊天也会通知你。

连续两分钟没有聊天在运行或等你时，实时会话会自动结束，也可以在常驻通知上点击**结束**。App 打开期间第一次有聊天运行时，会请求通知权限。不授权的话，App 切到后台就会断开连接。

## 随处访问

在家或办公室，手机直接通过网络连接电脑。想在其他网络下使用，需要在一台电脑和手机都能访问的服务器上运行中继，再到电脑上的**设置 → 连接 → 手机 → 随处访问**里填入中继地址和 Token。中继只转发加密后的数据，看不到你的聊天。

之前配对的手机下次和电脑处于同一网络时，会自动获取中继。中继的部署步骤见 Hub 文档中的[随处访问](../../developing/lifecycle/hub#随处访问)。
