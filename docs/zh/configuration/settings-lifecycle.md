# 设置何时生效

Desktop 在每组设置里显示相应的应用操作。

![Desktop 设置的生效方式](/settings-tiers-overview.svg)

## 应用设置

| 设置 | 操作 |
|---|---|
| 技能和 MCP 服务 | 保存后立即生效。 |
| 渠道插件设置 | 保存后重新连接渠道。 |
| 本地 AppServer 运行时和监听地址 | 选择**应用并重启**。 |
| 远端 AppServer 连接 | 选择**应用并连接**。测试成功后，Desktop 保存连接。 |
| 默认模型和偏好 | 保存后对新对话生效。已有对话保留原有选择。 |

## 修复远端连接

在连接错误页选择**打开设置**，修改地址或令牌，或切回本地模式。

个人与工作区设置的叠加方式见[配置](./)。
