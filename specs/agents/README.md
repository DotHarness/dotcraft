# Agent Specifications

Agent specs define coordination models for multi-agent work and external
subagent execution. They describe runtime behavior that builds on Session Core,
AppServer, and app/tool integration.

| [external-cli-subagent-design.md](external-cli-subagent-design.md) | External CLI subagent runtime model, abstractions, coordination, and approval propagation. |
