# DotCraft Dev Plugin

This plugin is for developing DotCraft itself. It packages the project-specific skills that help contributors follow DotCraft's development workflow, plan larger features, prototype Desktop UI changes, diagnose LLM/tool failures, refine SVG assets, and draft release notes.

Included skills:

- `dev-guide`
- `feature-workflow`
- `ui-prototype`
- `error-diagnosis`
- `svg-design`
- `release-draft`
