# DotCraft Dev Plugin

This plugin is for developing DotCraft itself. It packages the project-specific skills that help contributors follow DotCraft's development workflow, plan larger features, prototype Desktop UI changes, refine SVG assets, and draft release notes.

Included skills:

- `dev-guide`
- `feature-workflow`
- `ui-prototype`
- `svg-design`
- `release-draft`

> LLM/tool failure diagnosis moved to the built-in `dotcraft-doctor` plugin (the `error-diagnosis` skill).
