# DotCraft Dev 插件

这个插件用于开发 DotCraft 本身。它把 DotCraft 项目开发时需要的专用 skills 打包在一起，用于遵循仓库开发流程、规划较大的功能、制作 Desktop UI 原型、调整 SVG 资产，以及起草 Release 文案。

包含的 skills：

- `dev-guide`
- `feature-workflow`
- `ui-prototype`
- `svg-design`
- `release-draft`

> LLM/tool 失败诊断已移至内置插件 `dotcraft-doctor`（即 `error-diagnosis` skill）。
